# Pustaka Style Video

Pustaka 42 style edit video dengan contoh gerakan (CSS) dan prompt yang boleh disalin ke Claude Code atau Codex.

## Guna
Buka `index.html` dalam pelayar. Tiada build step. Font dimuat dari Google Fonts.

## Hos di GitHub Pages
Settings, Pages, Source: Deploy from a branch, branch `main`, folder `/ (root)`.

## Tambah style
Tambah satu baris dalam array `D` di dalam `index.html` (format dinyatakan dalam komen di atas array tersebut).
