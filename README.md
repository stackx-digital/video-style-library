# Pustaka Style Video

Pustaka 42 style edit video dengan contoh gerakan (CSS) dan prompt yang boleh disalin ke Claude Code atau Codex.

Ada juga tab **Ikon animasi**: 48 ikon daripada Lucide (ISC), Phosphor (MIT), Tabler Icons (MIT) dan Heroicons (MIT), dengan 6 animasi (Pop, Draw, Bounce, Pulse, Spin, Wiggle). Klik ikon untuk salin SVG dan CSS animasinya.

Tab **Transition** pula ada 37 transisi (Cut, Dissolve, Wipe, Zoom, Glitch, J-Cut, L-Cut dan lain-lain) dengan contoh gerakan, prompt, dan nama `xfade` FFmpeg bagi yang ada.

## Guna
Buka `index.html` dalam pelayar. Tiada build step. Font dimuat dari Google Fonts.

## Hos di GitHub Pages
Settings, Pages, Source: Deploy from a branch, branch `main`, folder `/ (root)`.

## Tambah style
Tambah satu baris dalam array `D` di dalam `index.html` (format dinyatakan dalam komen di atas array tersebut).

## Lesen ikon
Ikon disalin daripada pakej npm `lucide-static` (ISC), `@phosphor-icons/core` (MIT), `@tabler/icons` (MIT) dan `heroicons` (MIT). Simpan notis lesen asal jika mengedar semula.
